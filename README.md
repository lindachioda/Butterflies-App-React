# 🦋🌱 Butterfly Atlas

Welcome to **Butterfly Atlas**, a web application dedicated to discovering and exploring the fascinating world of butterflies!
Browse different butterfly species, search for your favorite ones, and discover useful information about each species through a clean and nature-inspired interface.
Butterfly Atlas is a personal learning project developed to practice React and TypeScript, work with external APIs, manage application state and build a complete responsive web application.

## 🛠️ Technologies Used

- **React** – Building reusable UI components.
- **TypeScript** – Static typing and improved code reliability.
- **Vite** – Development server and build tool.
- **React Router DOM** – Client-side routing and navigation.
- **Axios** – Making HTTP requests to external APIs.
- **Context API** – Managing shared application state.
- **React Hooks** – Managing state and side effects.
- **CSS3** – Styling and responsive layouts.
- **Lottie** – Displaying animated illustrations.
- **iNaturalist API** – Retrieving butterfly species data and images.
- **FormSpree** – Handles submissions end-to-end with storage.



## 🌍 API

This project uses the [iNaturalist API](https://api.inaturalist.org/v1/docs/) to retrieve butterfly information.
The application uses the API to search for butterfly species and retrieve individual species details, including their scientific names, common names, photographs and other available information.
